# Dota2 MMR Tracker

Веб-приложение для отслеживания расчётного MMR и подробной статистики матчей Dota 2. Данные профиля и матчей загружаются через OpenDota, интерфейс работает через локальный Express API.

## Возможности

- Подключение профиля по Steam account ID или SteamID64 и ввод стартового MMR.
- Начальная загрузка доступной истории без пересчёта старых матчей.
- Учёт новых рейтинговых побед и поражений по фиксированным +25/−25 MMR; повторная синхронизация не учитывает матч повторно.
- Ручная корректировка расчётного MMR и история ежедневных снимков `rank_tier`.
- Просмотр результатов, K/D/A, GPM, XPM, длительности и линии по загруженным матчам.
- Подробности разобранного матча: оба состава, счёт, командный перевес по золоту, опыт и фарм по минутам, net worth, предметы и покупки игроков, урон, лечение, варды и стаки лагерей.
- Журнал фактических покупок героя с временем каждой покупки и личной медианой тайминга на этом герое; сопоставление побед и поражений строится только по сохранённым разборам.
- Осторожные сигналы о предметах и таймингах появляются только при достаточной личной выборке и обозначены как корреляции, а не универсальный билд или доказанная причина победы.
- Если OpenDota ещё не разобрала матч, на странице матча можно поставить разбор в очередь; приложение автоматически проверяет готовность состава и статистики и сохраняет доступные GPM/XPM/ластхиты.
- Командный net worth и места игрока по GPM/ластхитам показываются только при наличии достаточных данных OpenDota; недоступные значения не подменяются оценками.
- Сводка матчей по героям, фильтр и сортировка.
- Единый каталог 127 героев: официальные имена Valve, стабильные ID и проверяемые изображения.
- Страница аналитики по сохранённым рейтинговым матчам: винрейт, KDA, доступные средние показатели, форма и активность за неделю.
- Локальные мини-игры «Угадай героя», «Викторина» и «Память» с рекордом в браузере; их результаты не смешиваются с матчевой статистикой.
- Сравнение двух публичных Steam-профилей по выборке до 100 последних рейтинговых матчей; сравнение не создаёт и не сохраняет профиль в базе.
- Каталог профессиональных игроков и команд из публичного списка OpenDota с поиском; при недоступности API отображается ошибка источника.
- Отдельные страницы достижений и настроек цветовой темы, уменьшения анимации и арта обложки профиля; фон аналитических страниц остаётся спокойным и не мешает чтению данных, а выбор арта сохраняется локально в браузере.
- Редактор карточки профиля с пятью шаблонами, тремя форматами PNG, выбором всех героев и отображаемых реальных показателей.
- Изображения героев для PNG-карточек загружаются через ограниченный same-origin маршрут из официального каталога, чтобы браузер не блокировал экспорт из-за CORS.
- Подробности источников: число игр и винрейт героев берутся из OpenDota, а GPM/XPM/KDA — из сохранённой в приложении рейтинговой истории.
- Ежедневная синхронизация профилей и сохранение снимка ранга в 03:15 UTC.

## Стек

- React, Vite, Recharts
- Node.js, Express
- PostgreSQL, Prisma 7
- OpenDota API, node-cron

## Требования

- Node.js 20+
- PostgreSQL для отдельного сервера либо встроенная локальная база PGlite для разработки
- Публичный профиль Dota 2. В настройках Dota 2 включите **Expose Public Match Data**.
- API-ключ OpenDota необязателен, но может помочь при ограничениях частоты запросов.

## Локальный запуск

Установите зависимости. Встроенная локальная база не требует `.env`. Для обычного PostgreSQL скопируйте `.env.example` в `.env` и укажите адрес базы:

```env
DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/dota_mmr_tracker?schema=public"
OPENDOTA_API_KEY=""
PORT=3001
CLIENT_ORIGIN="http://localhost:5173"
```

Сгенерируйте Prisma Client:

```bash
npm install
npm run db:generate
```

Если в `.env` не задан `DATABASE_URL`, API автоматически запускает встроенную PostgreSQL-совместимую базу PGlite. Схема применяется при первом запуске, данные хранятся в `.local-data/dota2-mmr-tracker` и не попадают в Git. Отдельный сервер базы для локальной разработки не требуется.

Запустите API и интерфейс в отдельных терминалах:

```bash
npm run dev:api
npm run dev
```

Vite проксирует `/api` на `http://localhost:3001`. API health check: `GET http://localhost:3001/api/health`.

Для обычного PostgreSQL задайте `DATABASE_URL` в `.env`, создайте базу и примените миграции через `npm run db:migrate`. Встроенная база предназначена для локальной разработки; для размещённого сервера используйте PostgreSQL.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/players` | Подключить профиль и задать стартовый MMR |
| `GET` | `/api/players/:accountId` | Профиль, статистика и снимки рейтинга |
| `PATCH` | `/api/players/:accountId/mmr` | Скорректировать расчётный MMR |
| `POST` | `/api/players/:accountId/sync` | Синхронизировать профиль и новые матчи |
| `GET` | `/api/players/:accountId/matches?limit=100&offset=0` | Страница сохранённых матчей (`matches`, `total`, `hasMore`) |
| `GET` | `/api/players/:accountId/matches/:matchId` | Подробности и таймлайны матча |
| `POST` | `/api/players/:accountId/matches/:matchId/parse` | Поставить матч в очередь разбора OpenDota |
| `GET` | `/api/assets/heroes/:heroId` | Изображение героя из официального каталога для PNG-экспорта |
| `GET` | `/api/players/:accountId/heroes` | Сводная статистика по героям |
| `GET` | `/api/players/:accountId/analytics` | Аналитика сохранённых рейтинговых матчей |
| `GET` | `/api/compare/:firstAccountId/:secondAccountId` | Сравнить два публичных профиля по последним рейтинговым матчам |
| `GET` | `/api/pro-players` | Публичный список профессиональных игроков OpenDota |

## Ограничения

Расчётный MMR — оценка, а не официальный рейтинг Valve. Изменение MMR в матчах, отмеченное символом `≈`, рассчитано приложением по фиксированной модели +25/−25 за рейтинговую игру и не является фактической дельтой Valve. Для ранее импортированных матчей без сохранённой оценки изменение отображается как неизвестное, а не как ноль. Число игр и винрейт в сводке героев отражают данные OpenDota, тогда как показатели фарма и KDA считаются по рейтинговым матчам, сохранённым приложением; это разные выборки. Сравнение таймингов и предметов использует только разобранные матчи того же героя с сохранённым журналом покупок (до 200 последних матчей). Новые данные накапливаются по мере разбора матчей; маленькая выборка не является мета-рекомендацией, а связь предмета с победой не доказывает причинность. OpenDota может ограничивать запросы, а таймлайны доступны только для разобранных матчей. История `rank_tier` начинается с даты подключения; ежедневные точки появляются, пока сервер запущен. Демо-значения и случайные результаты матчей не используются.
История матчей загружается страницами по 100 записей и поддерживает локальные фильтры по результату, герою, периоду и длительности, а также сортировку по времени и длительности. Хранятся только рейтинговые матчи, поэтому фильтр режимов не показывается. При доступности разбора в деталях дополнительно отображаются net worth, ластхиты, денайи и состав команд; неизвестные поля остаются пустыми. Аналитика сравнивает скользящие периоды в 7, 30 и 90 дней с непосредственно предшествующим отрезком такой же длительности; значения считаются по UTC-времени матча и не включают будущие даты. Средние K/D/A, длительность, GPM и XPM показывают размер фактической выборки; персональная статистика по героям доступна по выбранному периоду и не считается мета-рекомендацией.

Приложение не связано с Valve. Не помещайте пароли и API-ключи в исходный код и не публикуйте `.env`.
